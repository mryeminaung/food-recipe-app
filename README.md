# Food Recipe Browser 
A clean, responsive web application that allows users to explore, search, and view detailed food recipes, including ingredients and step-by-step cooking instructions.

## Live Demo
Check out the live application here: [food-recipe-browser.vercel.app](https://food-recipe-browser.vercel.app/)

## Features
* **Search Functionality:** Quickly find recipes by dish name or keyword.
* **Detailed Ingredients:** View a complete list of necessary items for every recipe.
* **Step-by-Step Instructions:** Easy-to-follow cooking guides.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
* **Fast Performance:** Built with Vite for lightning-fast development and loading.

## Installation & Setup

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/mryeminaung/food-recipe-browser.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd food-recipe-browser
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```

5.  **Open in your browser:**
    The app should now be running at `http://localhost:3000`.
