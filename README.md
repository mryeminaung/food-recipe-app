# 🍳 Recipe Browser

A modern recipe browsing web application built with **ReactJS** and powered by an external **Recipes API**.  
Users can search, explore, and view detailed recipes with ingredients, instructions, and more.

---

## ✨ Features

- 🔍 **Search Recipes** – Find recipes by name, ingredients, or keywords  
- 📖 **Recipe Details** – View ingredients, cooking steps, prep time, and servings  
- 🖼️ **Images** – Browse recipes with images for a better experience  
- ⭐ **Favorite Recipes** – Save your favorite recipes for quick access  
- 📱 **Responsive UI** – Works on desktop, tablet, and mobile  
- ⚡ **Fast & Modern** – Built with ReactJS, TailwindCSS (optional), and API integration  

---

## 🚀 Tech Stack

- **Frontend**: ReactJS (Hooks, React Router)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mryeminaung/recipe-browser.git
   cd recipe-browser
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Add your **API key**:  
   - Create a `.env` file in the project root  
   - Add your API key:
     ```env
     REACT_APP_API_KEY=your_api_key_here
     ```

4. Start the development server:
   ```bash
   npm start
   ```
